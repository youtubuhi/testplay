TEST PLAY - 테스트마다 카카오톡 링크 미리보기 달라지게 하기

변경한 파일 (총 3개 + 신규 1개)
- package.json: GitHub 자동 배포 시 테스트별 미리보기 HTML을 만드는 작업 연결
- src/content/tests/emoji-me.js: 첫 테스트의 공유 제목, 설명, 이미지 주소 설정
- scripts/generate-og-pages.mjs: 테스트별 페이지 자동 생성 (새 파일)

GitHub에 올리는 방법
1) testplay-og-update-only.zip 압축 풀기
2) GitHub https://github.com/youtubuhi/testplay 열기
3) Add file -> Upload files
4) 압축 푼 폴더의 package.json, src, scripts를 한번에 끌어 올리기
5) Commit changes
6) Actions 초록 체크 후 https://youtubuhi.github.io/testplay/test/emoji-me/ 를 카카오톡에서 공유

주의
- 기존 GitHub의 src/content/site.js, 인스타그램 주소, 기존 테스트 등은 변경하지 않습니다.
- 이 변경 파일만 업로드하면 됩니다.
- 결과 이미지가 아닌 '테스트 표지'를 공유하며, 친구는 테스트 시작 화면으로 이동합니다.
- 카카오톡은 기존 이미지 캐시를 저장할 수 있습니다. 변경 직후 안 보이면 카카오 OG 캐시 초기화를 시도하세요.

새 테스트를 만들 때 (src/content/tests/새테스트.js)
  thumbnail: '/images/새표지.png',
  shareTitle: '테스트 제목',
  shareDescription: '친구에게 보여줄 한 줄 소개',
  shareImage: '/images/새표지.png',

shareTitle / shareDescription / shareImage는 선택사항. 빠져 있으면 제목, 부제, 표지를 자동으로 사용합니다.

개발 검증
- node --check 통과
- HTML 자동 생성 스크립트 단독 실행 통과 (공개 테스트 1개)
- npm install 시간 초과로 실제 Vite 빌드 검증은 진행하지 못함. GitHub Actions 실행 결과로 최종 확인 필요.
